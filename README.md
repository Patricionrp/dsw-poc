# Proof of Concept: Herramientas de E2E Testing

## Descripción

Prueba de Concepto (PoC) desarrollada para la materia Desarrollo de Software de la Universidad Tecnológica Nacional – Facultad Regional Rosario (UTN FRRo).

El objetivo del proyecto es investigar, implementar y comparar dos herramientas de automatización de pruebas End-to-End (E2E): Cypress y Selenium.

## Tecnologías evaluadas

- Cypress
- Selenium

## Demostración

Para comparar ambas herramientas se utilizó el sitio de práctica SauceDemo, simulando un flujo de compra:

1. Inicio de sesión
2. Agregar un producto al carrito
3. Verificar el producto
4. Iniciar el proceso de checkout
